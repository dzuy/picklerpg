# Phase 5 — pattern practice

Full game → Practice focus offers eight tactical starting situations or Free play (no declared lesson). Start selected practice/game resets the current game, including opponent memory. Pattern practice is unscored; Next variation changes the contact side, lateral offset and depth. Height practice alternates high and low contacts. Original guided five-shot teaching and isolated Shot lab remain available.

The library covers middle pressure, drive/fifth-shot drop, wide/gap construction, middle-shading defenders, high/low decisions, pressure on a weaker defender, countering speed-ups, and split-depth opponents. These are live starting situations and learning objectives, not guaranteed scripted sequences. The weaker-defender drill currently varies reset ability rather than assigning a separate backhand rating; canned menus are preserved. Width and gap recognition are approximate; no precise coach-certified backhand targeting or sequence-success classifier is claimed.

The normal match provider handles legal choices, opponent responses, movement and execution from each setup. The opening two-bounce restriction is marked satisfied for these mid-rally starts. All team decisions remain explicit clicks. Free play keeps standard scoring and records tactical situations without displaying a lesson in advance.

## Exposure and review

Up to 500 recent decision records remain in memory for the browser session, across game restarts and variations. Each stores detected pattern, chosen intent, heuristic assessment and explanation. The exposure panel reports decisions, positive recognitions and review flags per pattern; one decision can appear in several patterns. These are decision counts, not unique games or independently verified successes. Refresh clears the records.

Post-point feedback is brief. It distinguishes tactical assessment from an immediate net/out execution fault on the final home shot. Other point losses do not automatically mean bad tactics. Heuristic categories include Good choice, Risky, Better target available, Correct idea/poor execution and Review target when the rules do not support a firm verdict.

Optional Replay and decision analysis provides a timeline slider and the recorded choice explanations. Up to 1,500 detached frames capture about 0.1-second intervals plus phase boundaries for the latest point. The slider renders saved positions/ball/shot state without altering the live result, score or random stream. Very long points may exceed the capture limit. Return to result exits playback; Next point/variation clears that point's replay.

Validation: 89 tests cover all varied setups, valid choices, live point completion, no practice scoring, retained exposure, replay isolation and existing full-game regressions. This is an initial heuristic practice layer; deeper positional coaching and sequence-level analysis can be expanded after playtests.
